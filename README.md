# Clementine

Clementine (Clementine Labs) was a New York based enterprise communication startup founded in 2013 and publicly launched in September 2014, offering workplace messaging, chat, and conference calling that let colleagues reach each other without exchanging personal mobile phone numbers.

It appears on the Andreessen Horowitz investment list and was **acquired by Dropbox in April 2016**, after which the Clementine service was shut down.

**Status: acquired / defunct — no API surface.** As of a 2026-07-20 probe, the company's primary domain `clementine.io` returns HTTP 301 to `https://www.dropbox.com/features/content-collaboration`. There is no public API, developer portal, documentation, or SDK to catalog. This profile is retained as a historical, non-operational record in the API Evangelist network.
